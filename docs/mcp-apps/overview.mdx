An MCP App is an HTML widget that a compatible MCP host displays when it calls your tool. Your server still returns useful data for the assistant; the widget adds a React interface beside it.

Start with [Build your first widget](/mcp-apps/quickstart). It begins with the Vite CLI and shows every file you need to edit.

## The three pieces

| Piece | What you write |
| --- | --- |
| Tool | A normal Toolgrain `tool()` that returns data and points to a widget URI |
| Widget | React components using `AppProvider` and `useToolResult()` |
| Resource | A `resource()` that returns the widget's built HTML |

Vite turns `weather.html` into `dist/widgets/weather.html`. The resource serves that file under a URI such as `ui://weather/widget.html`. The host loads the HTML and delivers the tool result to React.

Toolgrain handles the native Apps connection, result delivery, host styling, and widget sizing. Your application owns its UI and build. The host owns iframe creation, sandboxing, CSP enforcement, and permission grants.

## Follow the guides in order

1. [Build your first widget](/mcp-apps/quickstart): scaffold a React app, add the tool and resource, and connect a host.
2. [Use React hooks](/mcp-apps/react): add refresh calls, loading/error states, and optional host context.
3. [Add more widgets](/mcp-apps/build): build a separate HTML file for each resource.
4. [Permissions and metadata](/mcp-apps/security): edit one configuration object for the widget's needs.

For existing servers, use [Link tools and widgets](/mcp-apps/server). [Shared entries](/mcp-apps/shared-entries) and [host actions](/mcp-apps/host-actions) are optional follow-ups.

<Note>Apps and React require matching Toolgrain 0.3.0 or later packages. Check the [publication status](/project/releases#current-release-status) before installing. [Compatibility and acceptance](/mcp-apps/compatibility) records exact tested builds and live-host coverage.</Note>

Toolgrain implements the Apps protocol natively, without the official MCP or Apps SDKs. The iframe uses Apps revision `2026-01-26`, independently of the outer MCP connection. See the [protocol support table](/mcp-apps/capabilities#react-protocol-support) for the implemented messages.
