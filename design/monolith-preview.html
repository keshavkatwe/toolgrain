Define a tool.

A tool is a
small definition.

Describe the input. Write the handler. Toolgrain connects your application logic to MCP.

tools/greet.ts
import { tool } from "@toolgrain/mcp";
import { z } from "zod";

export const greet = tool({
  input: z.object({ name: z.string() }),
  execute: ({ name }) => `Hello, ${name}!`,
});
